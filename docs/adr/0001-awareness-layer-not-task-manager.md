# Awareness layer, not a task manager

unfocused mirrors open Loops from the apps where the work lives (Slack, Notion, Mail, Todoist, …) and links back to them. It never becomes the source of truth for the work and never asks the user to maintain a list. We chose this over building another todo app because the problem is losing track across many tools, not a missing tool. A replacement would add one more list to keep in sync. As a result, editing work in source systems (for example closing a Todoist task) is out of scope, and a Loop holds only enough to recognise the work and jump back to it.
